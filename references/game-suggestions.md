# Game planner — suggestion ledger

Memory for the `game-planner` agent (`.claude/agents/game-planner.md`). Every planning session appends a row here instead of overwriting — this is how the agent avoids re-suggesting the same game and can reason about past feedback. Entries are only edited in place to update `Status` (e.g. once a suggestion is accepted/rejected/implemented), never to delete history.
